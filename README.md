# Lab 1 — Типы данных в Go

Лабораторная работа №1 по дисциплине «Программирование на языке Go».
Тема: «Типы данных в Go».

## Описание

Программа демонстрирует работу с композитным типом данных `Employee`:
- добавление записей в срез структур,
- фильтрация (по отделу и по зарплате выше средней),
- сортировка (по зарплате и по имени),
- форматированный вывод через метод `ToString()`.

## Запуск

```
go run lab1.go
```
